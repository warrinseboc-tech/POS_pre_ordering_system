# Admin portal
Run the Python backend and open http://127.0.0.1:5050/admin/.
Sign in as ADMIN001 using ADMIN_PASSWORD from backend/.env.
Catalog, staff, expenses, sales, and payment proofs use MySQL through authenticated APIs.
Payment Verification is the only path to release online wallet orders to crew.
Confirm the real wallet transaction before approval; images alone cannot establish payment.
See ../README.md and ../docs/API.md for setup and routes.
